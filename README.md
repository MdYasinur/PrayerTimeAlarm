# নামাজের আজান (Prayer Time Alarm)

৫ ওয়াক্ত নামাজের (ফজর, যোহর, আসর, মাগরিব, এশা) সময় আজান বাজানোর Android অ্যাপ।

**Developer: Yasinur Rahman**

## ফিচার
- প্রতিটি ওয়াক্তের সময় ট্যাপ করে নিজের মতো বসানো যায়
- প্রতিটি ওয়াক্ত আলাদাভাবে চালু/বন্ধ করা যায়
- ফোনের যেকোনো আজানের MP3 ফাইল বাছাই করা যায়
- প্রতিদিন নিজে থেকেই আবার আজান সেট হয়; ফোন রিস্টার্ট হলেও কাজ করে
- নোটিফিকেশন থেকে "বন্ধ করুন" চাপলে আজান থামে
- আজান Alarm ভলিউমে বাজে

## আজানের অডিও
অ্যাপের সাথে কোনো আজানের অডিও দেওয়া নেই। দুইভাবে যোগ করা যায়:
1. অ্যাপ খুলে **"আজানের অডিও বাছাই করুন"** চেপে ফোন থেকে একটি MP3 বাছাই করুন, অথবা
2. বিল্ডের আগে `app/src/main/res/raw/azan.mp3` নামে ফাইল রাখুন (ফোল্ডার নিজে তৈরি করুন, নাম ছোট হাতের অক্ষরে)।

কোনোটি না থাকলে ফোনের ডিফল্ট অ্যালার্ম সাউন্ড বাজবে।

## APK বানানো
**Android Studio দিয়ে:** এই ফোল্ডারটি Android Studio-তে Open করুন → Gradle sync শেষ হলে
**Build → Build App Bundle(s) / APK(s) → Build APK(s)**।
APK পাবেন: `app/build/outputs/apk/debug/app-debug.apk`

**GitHub দিয়ে (Android Studio ছাড়া):** প্রজেক্টটি একটি GitHub repo-তে push করুন।
Actions ট্যাবে "Build APK" চলবে, শেষে Artifacts থেকে APK ডাউনলোড করুন।

## টিপস
- কিছু ফোনে (Xiaomi, Oppo, Vivo, Samsung) ব্যাটারি সেভার অ্যালার্ম আটকে দেয়।
  Settings → Apps → নামাজের আজান → Battery → **Unrestricted** করে দিন।
- Android 12-এ "Alarms & reminders" অনুমতি চাইলে চালু করে দিন।
